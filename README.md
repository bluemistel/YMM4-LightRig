# LightRig（ライトリグ）

シーンに **1つ置いた仮想光源** を、すべてのライティングエフェクトが**自動で参照する** YMM4（ゆっくりMovieMaker4）プラグインです。

立ち絵ごとにリムライトや影の向きを手作業で合わせる必要がなくなり、**光源を1つ動かすだけでシーン全体のライティングが追従**します。

> **LightRig** は 3DCG や撮影で使われる「ライトリグ（照明のセットアップ一式）」から。

---

## 特徴

- **シーン光源ターゲット**を1つ置くだけで、各エフェクトが**向き・色・強度・高さ**を自動参照
- 光源の色・強さを**背景の明るさへ自動追従**できる（環境光サンプラー連動）。シーンが暗くなればライティングも自動で落ち着く
- **点光源／平行光（太陽）／スポット**を選べ、点光源とスポットは**到達距離で減衰**させられる（既定はオフ。減衰の始まる位置も指定可）。街灯の前を通る立ち絵が自然に明るくなり、離れれば暗くなる
- **背景なじませ**は背景の**色味を乗算で移し、明るさは別枠で合わせる**「色調同化」方式。夕焼けでも夜でも、乗算／スクリーンを手で切り替える必要がありません
- **同じチャンネルに光源をいくつでも置けます**。距離減衰を重みに合成されるので、街灯が並ぶ道を歩けば**近い街灯から強く光を受ける**よう自動で移り変わります（チャンネルの切り替え操作は不要）
- **光源チャンネル（Ch1〜Ch8）**は照明グループの分け方に使えます（街灯群＝Ch1、月明かり＝Ch2 など）
- **プレビュー上のドラッグ操作点**で光源位置を直感的に調整。到達範囲の円・スポットの円錐・光の向きも表示されるので、数値を想像せず目で追い込める
- 光源が無い／チャンネル無効なら**単体エフェクトとしても動作**（手動の角度・色でそのまま使える）
- ゆらぎ（明滅）は乱数を使わず**フレーム基準で決定的に計算**。プレビューと書き出しが必ず一致し、FPS を変えても同じ実時間で同じ動きになる
- すべて **GPU 処理**（HLSL カスタムシェーダー／Direct2D）
- 主要パラメータは**キーフレームアニメーション対応**
- エフェクト追加メニューのカテゴリ **「LightRig」** にまとめて表示

## 動作環境

- ゆっくりMovieMaker4（**v4.55.1.1 で動作確認**。それ以前のバージョンは未確認です）
- .NET 10 ランタイム（YMM4 本体に準拠）
- x64 のみ

## インストール

1. [Releases](../../releases) から `LightRig.v.x.x.x.ymme` をダウンロード
2. ファイルを YMM4 のウィンドウにドラッグ＆ドロップ（または YMM4 のプラグイン管理から追加）
3. YMM4 を再起動

> 手動で配置する場合は、`LightRig` フォルダごと
> `（YMM4フォルダ）\user\plugin\` 以下に置いてください。

## 使い方

### 1. シーンに光源を置く

見た目に影響しない**空のアイテム**（空文字のテキスト、透明にした図形など）を作り、
映像エフェクトから **「シーン光源ターゲット」** を追加します。

> **街灯が複数ある構図では、光源ターゲットを複数置いてください。**
> 同じチャンネルに置けば距離減衰を重みに合成されるので、立ち絵が近づいた光源から強く光を受けます。
> 背景画像に描かれた街灯へ合わせる場合は、空アイテムをその位置へ置くだけで構いません。

> **たき火・ランプ・窓など「実際に光っているアイテム」に直接追加してもかまいません。**
> このエフェクトは映像を素通しするので見た目は変わらず、**そのアイテムが動けば光源も一緒に動きます**。
> 立ち絵より手前のレイヤーに置いても問題ありません（光源の位置はレイヤー順ではなく画面上の座標で決まります）。

- このエフェクトは映像を素通しするので、載せたアイテムの見た目は変わりません
- **アイテムの位置がそのまま光源の位置**になります（オフセットX/Y で微調整）
- プレビュー上に操作点が出るのでドラッグでも動かせます
- ⚠ **アイテムの尺がある区間だけ光源が発信されます。** ライティングを効かせたい区間に長さを合わせてください

### 2. 立ち絵にライティングを付ける

立ち絵アイテムに **「リムライト(光源連動)」** などを追加し、**光源と同じチャンネル**（既定 Ch1）を選ぶだけです。
必要なエフェクトだけを選んで貼れます。

### 3. （任意）背景の色を取り込む

**背景アイテム**に **「環境光サンプラー」** を追加し、光源と同じチャンネルを選びます。これで次の2つが使えるようになります。

- **背景なじませ** … 背景の色を立ち絵へ乗せて、浮きを抑える（光源の設置は不要）
- **シーン光源ターゲットの「環境光連動」** … 光の色・強さを背景の明るさへ自動追従させる

> YMM4 の映像エフェクトは自分のアイテムの画像しか受け取れないため、背景の色はこのサンプラー経由でしか取得できません。

## 収録エフェクト（9種）

### 光源（基盤）

| 名称 | 内容 |
|---|---|
| シーン光源ターゲット | 光源の位置・色・強度・高さ・ゆらぎを定義して発信する。映像はパススルー。**点光源／平行光（太陽）／スポット**の3種類と**到達距離による減衰**。**同じチャンネルに複数配置でき、距離減衰を重みに合成されます**。プレビューに操作点と到達範囲を表示。**環境光サンプラーへ色・明るさを自動追従**させることも可能 |
| 環境光サンプラー | 背景アイテムに挿し、背景の色を環境光として発信。**代表色**（画面内で最も明るい部分を基準にした相対しきい値で、空や光源の色を拾う）と、背景を**3x3に区切った位置ごとの色**の2つを配る |

### ライティング

| 名称 | 内容 | 主なパラメータ |
|---|---|---|
| リムライト(光源連動) | 光源側の輪郭を光らせる | 縁幅・ぼかし量・締まり・強さ・色ミックス・合成モード |
| シェーディング(光源連動) | 光源の反対側を暗くする。**エッジシェード**／**擬似ノーマル**の2モード | 濃さ・影色・幅・締まり・ぼかし量・フォルム・回り込み |
| 逆光 | 減光＋脱色でシルエット化し、光源側に強いリムを重ねる | 逆光の強さ・リム強さ／幅・ぼかし量・合成モード |
| 受光(光源連動) | シルエットから擬似法線を作り、**光の当たる側を光源色で明るくする**。シェーディングと対になる「明るくする側」。たき火・ネオンなど**色を持つ光源**を前面に置く用途 | 強さ・受光量・フォルム・広がり・回り込み・ぼかし量・合成モード・ハイライト／締まり・色ミックス |
| 落とし影(光源連動) | シルエットを接地線へ投影して地面に落ちる影を作る。**伸びる向き**で順光（奥へ）／逆光（手前へ）を選べる | 伸びる向き・長さ・傾き・接地位置・濃さ・ぼかし量・先端ぼかし・影色 |
| 空気遠近(デプスフォグ) | カメラ距離に応じて遠いレイヤーほど霞ませる | 開始／終了距離・カーブ・最大濃度・フォグ色・環境光ミックス |
| 背景なじませ(環境光連動) | **背景の色を被写体に乗せて浮きを抑える**。背景を3x3に区切った色を位置で補間するので、頭には空の色・足元には地面の色が乗る。**必要なのは環境光サンプラーだけで、光源の設置は任意** | 方式（色調同化／光を重ねる）・モード（グラデーション／全体）・色の取得（位置に応じた色／代表色）・強さ・色味の同化・明るさ合わせ・彩度・明るさ・背景の対応付け |

> **陰影は「暗くする側」と「明るくする側」で対になっています。**
> 光の反対側を暗くするのが**シェーディング**、光の当たる側を明るくするのが**受光**です。両方貼れば一通りの立体感が出ます。

## 設計上のポイント

- **陰影は絵柄をぼかさない**：「ぼかし量」は陰影の成分だけを平均するので、立ち絵のディテールは鮮明なままです。
- **擬似法線はアルファ（シルエット）から生成**：輝度から作ると服の柄や髪をシワとして拾うため、輪郭情報のみを使っています。
- **落とし影は「帯モデル」**：影の伸びる量に上限があるので、2D の立ち絵でも破綻せず、長さ・傾き・接地位置を手動補正できます。
- **空気遠近は他プラグイン不要**：`DrawDescription` のカメラ行列から距離を算出します。距離の目盛りは**標準カメラ位置を 0** としており、アイテムの Z 座標と一致します。
- **背景なじませは「色調同化」が既定**：背景色を輝度1に正規化してから乗算するので、色味の調整が明るさに影響しません。明るさは別パラメータで背景へ寄せます。合成モードで重ねる従来方式も「光を重ねる」として選べます。
- **背景なじませに光源は要りません**：必要なのは背景アイテムに挿した**環境光サンプラー**だけです（YMM4 の映像エフェクトは自分のアイテムの画像しか受け取れないため、背景の色はチャンネル経由で受け取ります）。光源があれば「どちら側から光が当たっているか」を反映できますが、**モード＝全体**を選べば光源を一切参照せず、シルエット全体へ均一に背景色を乗せます。

## 注意事項

- 影・リムは**アルファ（透明部分）を持つ素材**（立ち絵・PNG など）に適用してください。全面不透明の素材では輪郭が検出できません。
- **落とし影はアイテム自身の描画範囲にしか描けません**（背景アイテムの上には落ちません）。これは 2D 合成の構造上の制約です。
- **落とし影は必ず一番最後（下）に置いてください。** 影をアイテムの絵に描き込む仕組みのため、リムライト・受光・シェーディングより前に置くと、影の部分が「被写体の面」とみなされて光を受けてしまいます。
  推奨順序: 背景なじませ → シェーディング → リムライト → 受光 → **落とし影**
- 環境光サンプラーは GPU→CPU の読み戻しを行うため、負荷軽減として既定で 100ms おきに測定します（フレーム単位ではないので、プロジェクトの FPS を変えても追従の速さは変わりません）。
- **場面切り替え（トランジション）をまたいで配置した立ち絵**は、切り替え中に前後どちらの場面にいるか判別できません。切り替え中の見た目を厳密に分けたい場合は、立ち絵アイテムも切り替え位置で分割してください。

## ビルド方法（開発者向け）

- 環境変数または `Directory.Build.props` の `YMM4DirPath` に「開発用 YMM4」フォルダのパスを設定
- HLSL のコンパイルに **Windows SDK の `fxc.exe`** が必要（ビルド時に `.hlsl` → `.cso` へコンパイルし埋め込み）

```sh
# 開発用 YMM4 のプラグインフォルダへ配置（デバッグ用）
dotnet build -c Release -p:Platform=x64

# 配布用 .ymme を生成（publish\LightRig.v.<Version>.ymme）
dotnet build -c Release -p:Platform=x64 -p:PackYmme=true

# C# のみ検証（fxc 不要・シェーダーコンパイルをスキップ）
dotnet build -p:SkipHlsl=true -p:SkipPluginCopy=true
```
